Behind the work

A way into the catalogue.

A media discovery interface built around search, category navigation and an editorial introduction. A collaborative project by OVIO and Suvo (Gaurav Raj Singh).

An editorial first impression.

A serif introduction and orange action distinguish the public opening from the denser catalogue interface. Media artwork provides the colour; search remains visible above the opening.

Two scales of navigation.

The desktop capture groups discovery tools in a sidebar. The mobile capture uses bottom navigation and keeps account actions close to the introduction. Each layout changes hierarchy rather than shrinking the desktop screen.

Shared authorship, clear limits.

OVIO and Suvo contributed across the product. This study describes the visible public interface; it does not independently verify signed-in recommendations, personal history or backend integrations.

What this study shows

The imagery records the actual public interface. Feature descriptions are limited to visible screens and the existing project record. No user counts, recommendation accuracy or commercial outcomes are claimed.

The public catalogue

Let the media lead.

The catalogue changes the rhythm from editorial introduction to browsing. Artwork, titles and visible metadata form the discovery surface; this is a capture of the public product, not a fabricated collection.
